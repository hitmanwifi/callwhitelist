# Продуктовые правила фильтрации

Версия правил: `0.1`

## Режимы решения

Фильтр возвращает одно из решений:

- `ALLOW` — пропустить вызов;
- `BLOCK` — заблокировать вызов;
- `SILENCE` — не блокировать, но отключить звонок/уведомление, если это поддерживается системой.

В первой версии основной пользовательский режим — `ALLOW` или `BLOCK`. `SILENCE` оставляем в модели как расширение для следующих итераций.

## Правила по умолчанию

1. Экстренные номера всегда разрешены.
2. Номер из активного списка разрешённых номеров разрешён.
3. Контакт разрешён, если включена настройка «Разрешать контакты».
4. Активное временное правило применяется к номеру, если оно подходит по списку и времени.
5. Скрытые номера блокируются.
6. Номера, которых нет в разрешённых источниках, блокируются.

Значения по умолчанию можно изменить в настройках:

- разрешать или блокировать неизвестные номера;
- разрешать или блокировать скрытые номера;
- разрешать контакты;
- включать или отключать отдельные списки.

## Приоритеты

При конфликте применяется первое подходящее правило в следующем порядке:

1. экстренное исключение;
2. явное правило для конкретного номера;
3. активное временное правило;
4. специальный список;
5. правило для контактов;
6. правило для неизвестных/скрытых номеров;
7. глобальное действие по умолчанию.

Внутри одного уровня приоритет имеет более специфичное совпадение: полный номер выше маски, а маска выше группы.

## Нормализация номеров

Перед сравнением:

- удаляются пробелы, скобки, дефисы и другие разделители;
- сохраняется ведущий `+`, если он есть;
- номер хранится в формате E.164, когда его можно однозначно получить;
- локальные номера преобразуются с учётом выбранного региона устройства;
- если номер нельзя надёжно нормализовать, он считается неизвестным.

## Временные правила

Временное правило содержит:

- набор номеров, контактов или специальный список;
- дни недели;
- время начала и окончания;
- часовой пояс устройства;
- действие `ALLOW` или `BLOCK`;
- признак активности.

Интервалы через полночь поддерживаются: например, `22:00–07:00` действует до следующего дня. При пересечении нескольких правил побеждает правило с более высоким приоритетом, а при одинаковом приоритете — последнее изменённое пользователем.

## Журналирование

Для каждого обработанного вызова сохраняются:

- время;
- нормализованный номер, если он доступен;
- источник совпадения;
- итоговое решение;
- причина решения.

По умолчанию журнал хранится локально и может быть очищен пользователем. Сетевой обмен данными не требуется.

## Системные ограничения

Для работы приложения пользователь должен назначить его системным приложением фильтрации вызовов, если это требуется версией Android и устройством. Без этого состояния приложение показывает понятный статус «Фильтрация не активна», а сервис не считается работоспособным.

Доступ к контактам запрашивается отдельно и не является обязательным: без него работают явные списки номеров и временные правила.

## Нерешённые расширения

Оставлены для следующих этапов:

- импорт/экспорт списков;
- маски и диапазоны номеров;
- PIN/биометрическая защита настроек;
- облачная синхронизация;
- статистика заблокированных вызовов;
- режим «разрешить только во время активного расписания».
