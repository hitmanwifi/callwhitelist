# Белый список вызовов

Android-приложение для локальной фильтрации входящих вызовов по гибкому белому списку.

[English version](README.md)

## Возможности

- Разрешение вызовов от контактов и явно добавленных номеров.
- Настройка действий для неизвестных и скрытых номеров.
- Расписания с временными окнами, включая переход через полночь.
- Временные разрешённые номера на 1 час, 24 часа или 7 дней.
- Полное временное отключение фильтрации одним тумблером.
- Локальный журнал обработанных, разрешённых и заблокированных вызовов.
- Период статистики обзора: сегодня, 7 дней, 30 дней или всё время.
- Необязательные локальные уведомления о заблокированных вызовах.
- Интерфейс на русском и английском языках.
- Material 3 и стандартные Material icons.

## Приватность

Приложение рассчитано на локальную работу на устройстве:

- аккаунт не требуется;
- сетевые сервисы и аналитические SDK не используются;
- правила, настройки и журнал хранятся локально;
- доступ к контактам необязателен и используется только для распознавания сохранённых контактов;
- приложение не запрашивает `READ_CALL_LOG` и `WRITE_CALL_LOG`.

Privacy policy и документы открытой лицензии будут добавлены перед публичным распространением.

## Требования

- Android Studio со встроенным JDK.
- Настроенный Android SDK.
- Минимальная версия Android: API 26.
- Kotlin, Jetpack Compose, Material 3, Room и DataStore.

Перед обработкой входящих вызовов приложение нужно назначить системным обработчиком фильтрации вызовов. Это выполняется на экране «Политики».

## Сборка

Из корня проекта в Windows:

```powershell
$env:JAVA_HOME = "C:\Users\User\AppData\Local\Programs\Android Studio\jbr"
.\gradlew.bat clean :app:assembleDebug
```

Запуск unit-тестов домена:

```powershell
.\gradlew.bat :domain:test
```

Debug APK создаётся здесь:

```text
app/build/outputs/apk/debug/app-debug.apk
```

## Архитектура

```text
app/                  Compose UI, навигация и системная интеграция
callfilter/           CallScreeningService и горячий путь решения
core/model/           Kotlin-модели предметной области
core/database/        Room entities, DAO и database provider
core/preferences/     Настройки DataStore
core/designsystem/    Material 3 тема
data/                 Локальные хранилища и snapshot
domain/               Чистые правила фильтрации и unit-тесты
```

Проект использует Kotlin-first модульную структуру. Экраны разделены по файлам, но отдельный Gradle-модуль для каждого экрана не создаётся.

## Статус проекта

В текущую baseline-версию входят фильтрация, расписания, локальный журнал, уведомления, временные правила и модульная Kotlin-структура. Подготовка к публикации в Google Play отслеживается отдельно и пока отложена.
